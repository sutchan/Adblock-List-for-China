# Adblock List for China

[English](README.md) | [中文](README_CN.md)

专为中文网站优化的广告过滤规则列表，让您的浏览体验更加纯净。

## 支持的浏览器

- uBlock Origin（推荐）
- AdBlock Plus
- AdGuard
- 浏览器内置广告拦截器

## 快速开始

### 方法一：订阅（推荐）

在您的广告拦截扩展中添加此订阅地址：

```
https://raw.githubusercontent.com/sutchan/Adblock-List-for-China/master/adblock_list_for_china.txt
```

#### uBlock Origin

1. 点击浏览器工具栏中的 uBlock Origin 图标
2. 点击设置图标（齿轮）
3. 进入「过滤列表」标签页
4. 点击「导入...」
5. 粘贴上述订阅地址
6. 点击「应用更改」

#### AdBlock Plus

1. 点击浏览器工具栏中的 AdBlock 图标
2. 点击「选项」
3. 进入「高级」标签页
4. 滚动到「自定义过滤列表」
5. 勾选「添加您自己的过滤列表」
6. 粘贴上述订阅地址

### 方法二：手动导入

1. 下载 `adblock_list_for_china.txt`
2. 打开广告拦截扩展设置
3. 进入「自定义过滤列表」
4. 导入下载的文件
