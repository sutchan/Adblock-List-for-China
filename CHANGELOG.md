# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-05-09

### Added
- Added structured section headers for better rule organization
- Added filter list metadata header (title, version, description, home, issues, expires)
- Added bilingual comments (Chinese/English) for rule sections

### Changed
- Reorganized rules into categorized sections:
  - Generic Hiding Rules
  - Domain-Specific Hiding Rules
  - CSS Class Hiding Rules
  - Dot Class Hiding Rules
  - Site-Specific Rules (by category)
  - Network Rules (Image/CDN Blocking)
- Improved readability with consistent formatting

### Documentation
- Enhanced README.md with detailed installation instructions
- Added README_CN.md (Chinese version)
- Created CHANGELOG.md for version tracking
- Created metadata.json for project information
- Updated .gitignore with comprehensive entries

## [1.0.0] - Initial Release

### Added
- Initial 207 ad blocking rules for Chinese websites
- Support for major e-commerce platforms (Taobao, Tmall)
- Support for stock photo sites (Freepik, Pexels, Pixabay)
- Generic ad element hiding rules
- Network-level blocking rules for ad CDN domains
