# Adblock List for China

[English](README.md) | [中文](README_CN.md)

An ad blocking filter list specifically optimized for Chinese websites. Enjoy ad-free web browsing!

## Supported Browsers

- uBlock Origin (Recommended)
- AdBlock Plus
- AdGuard
- Browser built-in ad blockers

## Quick Start

### Method 1: Subscribe (Recommended)

Add this URL to your ad blocker extension:

```
https://raw.githubusercontent.com/sutchan/Adblock-List-for-China/master/adblock_list_for_china.txt
```

#### uBlock Origin

1. Click the uBlock Origin icon in your browser toolbar
2. Click the **Settings** icon (gear)
3. Go to **Filter lists** tab
4. Click **Import...**
5. Paste the subscription URL above
6. Click **Apply changes**

#### AdBlock Plus

1. Click the AdBlock icon in your browser toolbar
2. Click **Options**
3. Go to **Advanced** tab
4. Scroll to **Filter lists - custom**
5. Check **Add your own filter list**
6. Paste the subscription URL above

### Method 2: Manual Import

1. Download `adblock_list_for_china.txt`
2. Open your ad blocker extension settings
3. Go to **Custom filter lists**
4. Import the downloaded file

## Filter Categories

- **Stock Photos** - Freepik, Pexels, Pixabay, etc.
- **News & Media** - Content platforms
- **Productivity Tools** - SaaS applications
